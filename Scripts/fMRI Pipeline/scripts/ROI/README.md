# ROI Analysis

The `scripts/ROI/` folder contains region-of-interest (ROI) masks in NIfTI format and two notebooks: one for generating new spherical ROIs from MNI coordinates, and one for extracting mean ROI values from L1 contrast images.

ROI analysis is run after L1 modeling (Step 4). It does not require L2 results.

## `GenerateROISpheres.ipynb` — Creating Spherical ROIs

This notebook generates binary sphere masks centered on MNI coordinates and saves them as NIfTIs. It uses nilearn's `nifti_spheres_masker` internally, using an existing L2 T-map to define the voxel grid (resolution, affine, and brain mask) so that output ROIs are already in the same space as the contrast images used for extraction.

### How Spheres Are Generated

For each set of coordinates, the notebook:

1. Computes a brain mask from the reference T-map using `nilearn.masking.compute_brain_mask`
2. Generates a sparse affinity matrix defining which voxels fall within the sphere radius using `_apply_mask_and_get_affinity`
3. Projects this back to 3D image space using `_unmask_3d`
4. Saves the binary sphere as a NIfTI with the same affine as the reference image

### Creating a New Sphere

Copy the pattern from any existing cell and update the coordinates, radius, and output filename:

```python
from nilearn import plotting, masking
from nilearn.masking import _unmask_3d
from nilearn.maskers import nifti_spheres_masker
import nibabel as nib
from nibabel import Nifti1Image

coords = (x, y, z)   # MNI coordinates in mm
radius = 10           # sphere radius in mm

space_defining_image = masking.compute_brain_mask(
    "/data00/projects/geoscan_v2/data/bids_data/derivatives_nocorrection/nipype/"
    "task-image_model-GEO-condition/l2analysis/standardSmoke_v_standardNonsmoke/spmT_0001.nii"
)

_, A = nifti_spheres_masker._apply_mask_and_get_affinity(
    seeds=[coords], niimg=None, radius=radius,
    allow_overlap=False, mask_img=space_defining_image)

sphere_mask = _unmask_3d(
    X=A.toarray().flatten(),
    mask=space_defining_image.get_fdata().astype(bool))

sphere_mask = Nifti1Image(sphere_mask, space_defining_image.affine)
nib.save(sphere_mask, "MyROI_10mm.nii.gz")

plotting.plot_roi("MyROI_10mm.nii.gz", bg_img=space_defining_image)
plotting.show()
```

Always verify the sphere visually after saving — check that it falls in the expected anatomical location.

### Creating a Union Mask

To combine multiple sphere masks into a single ROI (e.g. for a multi-region hypothesis), use `nilearn.masking.intersect_masks` with `threshold=0`. Despite the function name, `threshold=0` produces a **union** — a voxel is included if it appears in *any* of the input masks:

```python
import nilearn
import nibabel as nib

unionmask = nilearn.masking.intersect_masks(
    ["Sphere1.nii.gz", "Sphere2.nii.gz"],
    threshold=0,      # 0 = union (voxel in any mask); 1 = intersection (voxel in all masks)
    connected=False
)
nib.save(unionmask, "MyUnion_10.nii.gz")
```

The Lin and Engelmann union masks in this folder were both created this way.

## `extract_ROIs_from_first_level_models-GEO.ipynb` — Extracting ROI Values

This notebook extracts the mean contrast estimate within each ROI for every subject and contrast in the L1 output, producing a single long-format CSV for downstream analysis in R or Python.

### How Extraction Works

For each subject × contrast × ROI combination, the notebook:

1. Loads the subject's L1 contrast image (`con_*.nii`)
2. Binarizes the ROI mask (any non-zero voxel → 1)
3. Resamples the binary ROI to match the contrast image's voxel grid using nearest-neighbor interpolation
4. Computes the element-wise product of the contrast image and the resampled ROI
5. Takes `nanmean` of the result — this is the mean contrast estimate across all voxels within the ROI

Resampling is done once per ROI per model directory (using an example contrast image from the first available subject) rather than once per subject, which is efficient as long as all subjects' contrast images share the same grid (which they do, since they come from the same fMRIPrep MNI-space output).

### Configuration

Two dictionaries at the top of the notebook control what is extracted:

**`roi_dict`** — the ROIs to extract from. Add or remove entries here to change which masks are used:

```python
roi_dict = {
    'Lin':   '/data00/projects/geoscan_v2/scripts/ROI/LinUnion_10.nii.gz',
    'Bartra': '/data00/projects/megameta/.../Bartra_fig9_striatum_vmpfc.nii',
}
```

**`model_dir`** — the L1 output directories to extract from. Each key is a project/session label; each value is a list of `[task_label, path]` pairs. Multiple model directories can be listed to pool subjects across sessions or cohorts into a single output file:

```python
model_dir = {
    'gs_t2': [['IMAGE', '/data00/projects/geoscan_v2/data/bids_data/derivatives_nocorrection/nipype/task-image_model-GEO-condition/']],
    'gs_t3': [['IMAGE', '/data00/projects/geoscan_v2/data/bids_data/derivatives_nocorrection/nipype/task-image_model-GEO-condition/']],
}
```

### Output

The notebook writes `roi_metaanalyses_geo_{date}.csv` to the working directory (wherever the notebook is run from — move it to a stable output location after running). The CSV is in long format with one row per subject × contrast × model directory:

| Column | Description |
|--------|-------------|
| `participant_id` | Subject folder name (e.g. `sub-GEO053`) |
| `study` | Key from `model_dir` (e.g. `gs_t2`) |
| `task` | Task label from the model_dir entry (e.g. `IMAGE`) |
| `contrast` | Contrast name from `SPM.mat` (e.g. `smoke_v_nonsmoke_all`) |
| `Lin` | Mean contrast estimate within the Lin ROI |
| `Bartra` | Mean contrast estimate within the Bartra ROI |
| *(one column per ROI in `roi_dict`)* | |

### Running the Notebook

1. Confirm that L1 modeling is complete for the subjects and model you want to extract from
2. Update `roi_dict` and `model_dir` at the top of the notebook if needed
3. Run all cells — the notebook prints progress per subject and writes the CSV on each outer loop iteration, so partial results are saved even if it is interrupted
4. Move the output CSV to `data/` or another stable location and rename it descriptively

### Adding a New ROI

To extract from a new mask, add it to `roi_dict` with an absolute path:

```python
roi_dict['MyNewROI'] = '/data00/projects/geoscan_v2/scripts/ROI/MyROI_10mm.nii.gz'
```

The notebook will display each ROI as a sanity check plot before extraction begins. Verify that the mask covers the intended anatomy before proceeding.

## Troubleshooting

**`NO FIRST LEVEL MODEL - skipping ROI extraction`**
The notebook checks whether each subject's output directory exists. Subjects whose L1 jobs failed or haven't run yet are silently skipped with this message. Check L1 outputs for those subjects.

**Resampling artifacts**
The ROI is resampled to match the first contrast image found in the first subject's directory. If a subject's contrast images are in a different voxel space for any reason, the resampled ROI may not align correctly. This is unlikely if all subjects were preprocessed with the same fMRIPrep settings.

**Sphere falls outside the brain mask**
If a coordinate is near the edge of the brain or in a region with variable coverage across subjects, some voxels in the sphere may be outside the brain mask used at generation time. The sphere will still be created but will be smaller than intended. Check the plotting output after generating the mask to confirm coverage.

**Output CSV is in the wrong location**
The notebook saves to the working directory (`./roi_metaanalyses_geo_{date}.csv`), which is wherever Jupyter was launched from. After running, move the file to a stable location such as `data/` and add the date and model name to the filename if not already present.
